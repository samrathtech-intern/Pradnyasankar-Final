# Pradnyasanskar Premium Landing Page


## Final visual-polish revision

This package includes the redesigned editorial hero, trust carousel, non-cropping wellness-focus expansion, varied routine cards, improved product-format carousel, readable range cards and readable campaign gallery requested in the final review.

A complete responsive landing page for Pradnyasanskar Enterprises Pvt. Ltd., built with Next.js, React, TypeScript, Tailwind CSS and Framer Motion.

## Included

- Three-slide animated campaign hero
- Sticky navigation, mega menu and mobile drawer
- Wellness-focus and routine carousels
- Filterable product discovery with quick view, wishlist and wellness bag
- Ayurveda and nutraceutical range storytelling
- Image-led campaign gallery and gifting sections
- Interactive routine finder and product-information experience
- Ingredient education, knowledge, community and business-enquiry sections
- Search overlay, saved-products drawer, bag drawer and mobile bottom navigation
- Reduced-motion support and responsive interactions
- Optimized local WebP image library

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production build

```bash
npm run validate
npm run build
npm start
```

## Content and compliance

The page avoids fabricated customer reviews, licence numbers, certification badges and medical claims. Product discovery language remains general and directs visitors to individual product information for composition, directions and cautions.
